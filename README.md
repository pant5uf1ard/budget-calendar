# 하루한도

다음 입금일과 저축 목표를 기준으로 오늘부터 하루에 얼마까지 써도 되는지 보여주는 생활비 캘린더 앱입니다.

## 핵심 기능

- 현재 자유 생활비, 수입일, 고정 지출, 저축 목표 기반 하루 한도 계산
- 날짜별 지출 기록과 메모
- 평일/주말 생활 패턴별 예산 배분
- 캘린더에서 초과/절약/오늘/고정 지출 상태 확인
- 모든 데이터는 현재 버전 기준 기기 안에만 저장
